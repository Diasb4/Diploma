# AITU Diploma Advisor Portal

Официальный статический веб-каталог и интерактивная платформа для выбора научных руководителей и тем дипломных проектов для студентов Astana IT University.

---

## Архитектура

* Данные и интерфейс хранятся в статических файлах (`HTML`, `CSS`, `JS`, `JSON`); отдельный сервер и база данных не требуются.
* Поиск, фильтрация и пагинация выполняются в браузере по локальному набору данных.
* Проект можно опубликовать на GitHub Pages, Vercel или Netlify.
* Каталог можно открыть локально через `index.html` без запуска сервера.

---

## Возможности

1. **Санитизация и нормализация данных (`scripts/sanitize.py`)**:
   - Очистка от всех неформальных/мемных студенческих тегов и субъективных оценок.
   - Сшивание преподавателей с реальными дисциплинами из университетского расписания.
   - Автоматическая классификация по 12 ключевым IT-направлениям (*AI/ML, Data Science, Web & Backend, Mobile, CyberSec, GameDev, IoT, DevOps, IT Management*).
   - Генерация рекомендуемых тем дипломных работ и требований к студентам.
   - Расчет доступных слотов для дипломного руководства.

2. **Поиск и фильтрация на UI**:
   - Мгновенный живой поиск по ФИО, дисциплинам, ключевым словам темы и email.
   - Быстрые фильтры-теги (Pills) с бейджами количества преподавателей.
   - Фильтр по университетским департаментам и кафедрам.
   - Чекбокс «Только со свободными местами».
   - Сортировка по академическому опыту, алфавиту, свободным местам или числу дисциплин.

3. **Интерактивные карточки и модальные окна**:
   - Карточки с цветными аватарами, индикатором доступности слотов (зеленый / желтый / красный) и тегами.
   - Модальный профиль: полный список дисциплин и темы диплома с кнопкой «Копировать».
   - **Генератор официального обращения к научруку:** автоматически формирует структурированное письмо с подстановкой ФИО студента, группы и выбранной темы с поддержкой `mailto:` и копированием.
   - **Избранное / Шортлист:** сохранение понравившихся преподавателей в `localStorage`.
   - **Памятка студенту:** пошаговый гайд по выбору темы и этикету первого письма.
   - **Тёмная и светлая тема** с сохранением выбора пользователя.

## Структура проекта

```
Диплом_сайт/
├── index.html               # Главная страница каталога
├── css/
│   └── styles.css           # Современная дизайн-система (Glassmorphism, Dark/Light темы)
├── js/
│   └── app.js               # Клиентская логика поиска, фильтрации, модалок и писем
├── data/
│   ├── professors.json      # Очищенный массив 346 преподавателей с темами
│   ├── stats.json           # Агрегированная статистика направлений и кафедр
│   └── professors_data.js   # JS-бандл для оффлайн/file:// запуска
├── scripts/
│   └── sanitize.py          # Python ETL-скрипт очистки и нормализации сырого дампа
├── dump_parsed.json         # Исходный дамп
└── README.md                # Документация проекта
```

## Локальный запуск

### Вариант 1: Быстрый запуск через браузер
Просто откройте файл `index.html` в любом браузере (Google Chrome, Edge, Safari, Firefox).

### Вариант 2: Локальный веб-сервер
```bash
# Python
python -m http.server 8080

# Открыть в браузере
# http://localhost:8080
```

---

## Обновление данных из нового дампа

Если вам передали свежий `dump_parsed.json`, просто запустите ETL-скрипт:

```bash
python scripts/sanitize.py
```

Скрипт автоматически пересоберет `data/professors.json`, `data/stats.json` и `data/professors_data.js`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте в него проект:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Diploma supervisor catalog"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
2. В репозитории GitHub откройте **Settings**, затем **Pages**.
3. В поле **Branch** выберите `main` и папку `/(root)`, нажмите **Save**.
4. Через 1 минуту ваш сайт будет доступен по ссылке `https://<ваш-логин>.github.io/<имя-репозитория>/`.
