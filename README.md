# AITU Diploma

Веб-приложение для выбора темы дипломного проекта, научного руководителя и команды в Astana IT University.

## Возможности

- Каталог тем с поиском, фильтрами, сортировкой, свободными местами и избранным.
- Каталог 346 преподавателей с поиском по интересам и постепенной отрисовкой списка.
- Профиль студента и подписанная серверная сессия.
- Атомарное бронирование темы командой до трёх человек.
- Мои заявки, уведомления, отмена заявки и экспорт данных листа согласования.
- Проверка инициативной темы на сходство с каталогом и отправка на рассмотрение.
- Дорожная карта дипломного проекта с редактируемым прогрессом.
- Светлая и тёмная темы, клавиатурная навигация, доступные диалоги и PWA.

## Архитектура

- `src/` — React 18, TypeScript, Vite и Tailwind CSS.
- `server/src/` — Express API, подписанные HMAC-сессии, проверка доступа, rate limit и атомарные операции.
- `data/topics.json`, `data/professors.json` — исходные каталоги.
- `data/runtime-state.sqlite` — постоянная SQLite-база изменяемого состояния. Файл создаётся автоматически и не хранится в Git.
- `tests/` — тесты движка похожести, mutex и интеграционные тесты HTTP API.

Старый прототип в `css/` и `js/` не участвует в сборке и сохранён только как исходная история проекта.

## Локальный запуск

Требуется Node.js 24 или новее.

```bash
npm ci
copy .env.example .env
npm run dev
```

Клиент: `http://localhost:5173`. API: `http://localhost:5000/api/health`.

Для демонстрации можно войти как `student.2026@astanait.edu.kz`. Текущий адаптер подтверждает домен и выдаёт подписанную восьмичасовую сессию; для реального университета маршрут `/api/auth/login` следует подключить к SSO AITU.

## Переменные окружения

- `PORT` — порт production-сервера, по умолчанию `5000`.
- `AUTH_SECRET` — секрет подписи сессий. В production обязателен уникальный длинный ключ.
- `ALLOWED_ORIGINS` — разрешённые Origin через запятую.
- `DATA_FILE` — путь к изменяемому хранилищу.

## Проверка

```bash
npm run typecheck
npm test

npm run verify
```

```bash
npm run verify
```

CI выполняет типизацию, тесты и production-сборку для каждого push и pull request.

## Docker

```bash
docker compose up --build
```

Приложение доступно на `http://localhost:5000`. Изменяемые данные находятся в named volume `aitu-data` и сохраняются между перезапусками контейнера.

Перед публичным развёртыванием задайте `AUTH_SECRET` и `ALLOWED_ORIGINS` через окружение.
